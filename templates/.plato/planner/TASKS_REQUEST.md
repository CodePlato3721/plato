## .tr.md Specification (TR Specification)

`.tr.md` (tasks review request) is the review request generated by the Planner agent at the end of the task-breakdown phase, used to confirm the task split with the user.

### Format

```
Task Count: <number of tasks after the split>
Split Summary: <brief description of how the tasks were split>

New Rules:
<rule file>: <rule text>
```

Example:

```
Task Count: 3
Split Summary: Split in the order db -> api -> ui, one independent task per layer.

New Rules:
PLAN_RULES.md: db task should always be an individual task
```

### Field Descriptions

- **Task Count**: The total number of tasks in `tasks.json`.
- **Split Summary**: A brief description of the reasoning and basis for this task split.
- **New Rules**: Format `<rule file>: <rule text>`, one rule per line. Leave empty if there are no new rules to add.
